# Emacs skills (vendored)

Copied from https://github.com/xenodium/emacs-skills (commit a158238, 2026-07-21).
Skipped macOS-only skills: swiftui-preview, xcode-*, mappu.

Update: `git clone --depth 1 https://github.com/xenodium/emacs-skills /tmp/emacs-skills`
then re-copy the directories listed here. Upstream's supported install is the
Claude plugin (`claude plugin marketplace add xenodium/emacs-skills`), which
installs globally instead of per-repo.

Requires a running Emacs server and `emacsclient` on `$PATH`.
